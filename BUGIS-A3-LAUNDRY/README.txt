BUGIS A3 LAUNDRY - WEBSITE BOOTSTRAP
====================================

Isi folder:
- Website customer: Home, Layanan, Harga, Kalkulator, Pesan, Cek Status, Testimoni, Galeri, Kontak
- Admin prototype: admin/login.html, dashboard.html, pesanan.html, struk.html
- CSS: css/style.css
- JavaScript: js/script.js

CARA MENJALANKAN:
1. Ekstrak folder BUGIS-A3-LAUNDRY.
2. Buka index.html di browser.
3. Untuk admin prototype, buka admin/login.html.

CATATAN TEKNIS:
- Menggunakan Bootstrap 5 melalui CDN.
- Data pesanan prototype disimpan di localStorage browser.
- Nomor transaksi otomatis dibuat seperti BUGIS-0001.
- Struk dapat dicetak dari admin/pesanan.html.
- Belum menggunakan PHP/MySQL, sehingga data belum menjadi database bersama antar perangkat.
- Login admin masih prototype front-end.
