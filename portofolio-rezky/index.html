Hubungi Saya
Selamat Datang di Portofolio Saya!

Halo! Saya Rezky Awalya, seorang mahasiswa semester 3 pada program studi Teknik Komputer, Jurusan Teknik Informatika & Komputer (JTIK), Universitas Negeri Makassar (UNM). Saya memiliki minat mendalam di bidang pemrograman sistem, perancangan antarmuka pengguna (UI/UX), desain grafis, serta public speaking dan debat.

Website portofolio ini dibangun berdasarkan standar modular HTML5 dan lembar gaya eksternal (CSS) sesuai kaidah modul praktikum pemrograman web, mengimplementasikan selector terstruktur, tata letak multi-kolom (*float layout*), navigasi dropdown menu bertingkat, dan efek visual interaktif.

Bahasa Pemrograman & Keahlian yang Dikuasai

Berikut adalah bahasa dan teknologi yang telah saya pelajari dan terapkan dalam tugas maupun proyek akademik:

C++ (C Plus Plus) Tingkat Menengah

Bahasa utama untuk memahami algoritma, struktur data, pemrograman berorientasi objek (OOP), serta manipulasi memori dan sistem tingkat rendah pada perkuliahan Teknik Komputer.

PHP (Hypertext Preprocessor) Pemrograman Web

Digunakan dalam pemrosesan backend web dinamis, logika server-side, pengolahan form, dan pengolahan data pada praktikum pemrograman web.

HTML (HyperText Markup Language) & CSS Frontend Dasar

Membangun struktur semantik halaman web, form interaktif, penyusunan tabel, serta pengaturan tampilan grafis yang responsif menggunakan Cascading Style Sheets.
