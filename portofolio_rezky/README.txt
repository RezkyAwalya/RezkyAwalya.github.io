PORTFOLIO REZKY AWALYA
========================

File:
- index.html   -> Beranda
- about.html   -> Tentang Saya
- contact.html -> Kontak
- style.css    -> seluruh styling
- script.js    -> dark mode, filter, modal, animasi, validasi form
- assets/profile.jpg -> foto profil

Cara menjalankan:
1. Ekstrak folder.
2. Buka index.html di browser.
3. Jika menggunakan NetBeans/VS Code, buka folder portfolio sebagai project.
4. Ganti link WhatsApp, Instagram, dan GitHub di contact.html dengan link akun kamu.

Catatan:
Form kontak saat ini melakukan validasi dengan JavaScript. Belum mengirim pesan ke server karena tidak menggunakan backend.
